Simple Calculator
A basic command-line calculator program written in Python that performs four fundamental arithmetic operations.
Features

Addition: Add two numbers
Subtraction: Subtract one number from another
Multiplication: Multiply two numbers
Division: Divide one number by another

How It Works
The program presents a menu of four operations, prompts the user to select an operation and input two numbers, then displays the result of the chosen calculation.
Usage

Run the program
Select an operation by entering a number (1-4):

1: Addition
2: Subtraction
3: Multiplication
4: Division
