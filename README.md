Simple Calculator (Python)

A basic command-line calculator application written in Python that performs four fundamental arithmetic operations. This project is ideal for beginners to understand user input, conditional logic, and basic function handling in Python.

🚀 Features

Addition – Add two numbers

Subtraction – Subtract one number from another

Multiplication – Multiply two numbers

Division – Divide one number by another (with basic error handling)

🛠️ Technologies Used

Python 3

Command Line Interface (CLI)

📋 How It Works

The program displays a menu of arithmetic operations.

The user selects an operation by entering a number (1–4).

The user inputs two numbers.

The program performs the selected calculation.

The result is displayed on the screen.



🔢 Operation Menu
1. Addition
2. Subtraction
3. Multiplication
4. Division
